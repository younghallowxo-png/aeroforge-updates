# AEROFORGE — канал обновлений и веб-версия

Отсюда установленные версии AEROFORGE (Windows, macOS, Android) скачивают обновления.

- `latest.json` — номер последней версии и цифровая подпись
- `index.html` — сама игра (её же можно открыть в браузере)
- `manifest.json`, `sw.js`, `icon-*.png` — чтобы игру можно было установить на iPhone/Android с сайта (GitHub Pages)

Чтобы выпустить обновление — замените `index.html` и `latest.json` новыми (их готовит Claude).
