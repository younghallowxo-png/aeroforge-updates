# AEROFORGE — канал обновлений

Отсюда установленная игра AEROFORGE скачивает обновления.

- `latest.json` — номер последней версии и цифровая подпись
- `index.html` — сама игра

Чтобы выпустить обновление, замените оба файла новыми (их готовит Claude) — у всех игроков игра обновится при следующем запуске.
